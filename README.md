# Temperature Converter

A simple iOS application built with SwiftUI that converts Celsius to Fahrenheit.

## Features

- Convert Celsius to Fahrenheit
- Input using TextField
- Reset button
- Simple and clean interface

## What I learned

- Using `TextField`
- Managing state with `@State`
- Creating and calling functions
- Converting `String` to `Double`
- Using optional binding with `if let`
